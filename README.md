# MUSAI Partners

주식회사 뮤사이파트너스 회사 소개 및 개인투자조합 소득공제 안내 사이트.

- 정적 단일 페이지 (`index.html`) — 빌드 과정 없음
- 투자설명서형 단일 문서 구조: 표지 → 목차 → 01 회사 · 02 사업영역 · 03 연혁과 인증 · 04 소득공제 제도(별표 B 절세액 산출) · 05 참여 절차와 위험 · 06 문의
- 상단 고정 헤더: MUSAI 마크 + 현재 장 번호 + 「소득공제 안내」 상주 버튼 (04장 진입 시 ● 현재위치 표시)
- 구버전 해시(`#tax`, `#t-calc` 등)는 새 앵커로 자동 매핑 — 기존 공유 링크 유지
- 검색엔진 비노출(`noindex`) — 링크를 통한 개별 공유 목적
