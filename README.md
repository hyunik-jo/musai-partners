# MUSAI Partners

주식회사 뮤사이파트너스 회사 소개 및 개인투자조합 소득공제 안내 사이트.

- 정적 단일 페이지 (`index.html`) — 빌드 과정 없음
- 2-도어형 진입: 홈에서 「회사 소개(#company)」 / 「조합 안내(#fund)」 두 동선으로 분리
- 회사 소개: 사업영역(번호 목록) · 연혁(표) · KOMCA 인증 도판 · 회사 정보
- 조합 안내: 요건 4줄 요약 → 제도 상세 → 절세액 계산기(기입란+산출표+샌키) → 절차 → 위험 → FAQ
- 상단 고정 헤더: MUSAI 마크 + 「소득공제 안내」 상주 버튼 (조합 안내 진입 시 ● 표시)
- 구버전 해시(`#tax`, `#t-calc` 등)는 새 앵커로 자동 매핑 — 기존 공유 링크 유지
- 검색 노출 허용(robots.txt·sitemap.xml). 페이지는 제도·회사 정보 제공만 담고 조합 모집 조건은 싣지 않음(사모 요건)
